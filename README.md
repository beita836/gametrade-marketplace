# GameTrade - 游戏交易市场

一个现代化的游戏交易市场应用，支持游戏饰品租赁、陪玩服务和数字商品交易。

## 🎮 功能特性

- **热门分类浏览** - CS2、三角洲、PUBG 等多个游戏分类
- **商品展示** - 美观的网格布局展示热门商品
- **卖家信息** - 查看个人卖家等级、好评率和成交数
- **订单管理** - 完整的订单查询和管理系统
- **个人中心** - 用户档案、订单历史、发布商品
- **响应式设计** - 完美适配桌面和移动设备

## 🚀 快速开始

### 在线访问
直接打开 `index.html` 文件即可使用，无需服务器配置。

**在线地址：** [https://beita836.github.io/gametrade-marketplace](https://beita836.github.io/gametrade-marketplace)

### 本地运行
1. 克隆仓库
   ```bash
   git clone https://github.com/beita836/gametrade-marketplace.git
   cd gametrade-marketplace
   ```

2. 用浏览器打开 `index.html`
   ```bash
   open index.html
   # 或在浏览器中直接打开文件
   ```

## 📱 页面导航

- **首页** - 热门分类、热门商品、热门卖家
- **市场** - 浏览全部商品（支持分类和搜索）
- **订单** - 查询订单（按订单号或买家名称）
- **我的** - 个人中心、订单管理、发布商品

## 🛠 技术栈

- **前端框架** - Vue.js 2.7
- **样式** - 原生 CSS（响应式设计）
- **图片** - picsum.photos 随机图片服务
- **头像** - pravatar.cc 用户头像生成

## 🎨 自定义

### 修改商品
编辑 `index.html` 中的 `PRODUCTS` 数组：
```javascript
PRODUCTS=[
  {
    id: 1,
    title: "你的商品名",
    shop: "你的店铺名",
    price: 100,
    sales: 128,
    game: "游戏类型",
    img: "图片URL"
  }
  // ... 更多商品
]
```

### 修改订单
编辑 `ORDERS` 数组，添加初始订单数据。

### 修改卖家信息
编辑 Vue 实例中的 `sellers` 数组。

## 📝 主要功能说明

### 搜索功能
- 在顶部搜索框输入关键词
- 支持搜索商品名称、卖家名称、游戏名称
- 点击搜索按钮或进入市场页面

### 分类筛选
- 支持多个分类切换
- 热门分类：全部、CS2、三角洲、PUBG、数字商品

### 订单查询
- 按订单号查询
- 按买家名称查询
- 查看订单详情

### 发布商品
- 在"我的"页面点击"发布商品"
- 输入商品名称和价格
- 自动添加到商品列表

## 🔐 注意事项

- 数据存储在浏览器内存中，刷新页面后会重置
- 如需持久化存储，建议接入后端 API
- 所有外部资源（图片、头像）依赖第三方服务
